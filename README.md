# EthernetWizard

I'm Merlin. I build things where networks, electronics, and software meet: custom device interfaces, ESP32 enclosures, and Linux themes. The dragons are mostly firewalls these days.

[The Lab and project writeups](https://ethernetwizard.com/) · [All repositories](https://github.com/EthernetWizard?tab=repositories)

## Start here: EthernetWizard Pager Theme

A wizard-themed interface for the Hak5 WiFi Pineapple Pager, with pixel art, custom menus, and animations.
